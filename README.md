# Бот «ДЕТИ ЕДЯТ!» — автоматические заявки в Telegram

Бот встречает клиента, задаёт несколько вопросов о заявке (сколько детей, какое
питание, адрес, контакты, согласие на обработку персональных данных), сразу
подтверждает приём заявки клиенту и пересылает вам оформленную заявку в чат.

## Шаг 1. Создать бота через BotFather

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, придумайте имя (например «Дети едят!») и username,
   заканчивающийся на `bot` (например `deti_edyat_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExampleTokenHere`. Сохраните
   его — он понадобится ниже. Никому не показывайте и не публикуйте этот токен.

## Шаг 2. Узнать свой chat_id (куда бот будет слать заявки)

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram и нажмите Start.
2. Бот пришлёт ваш `Id` — например `987654321`. Это и есть `OWNER_CHAT_ID`.
   (Если заявки должны приходить в отдельную группу — добавьте туда бота
   администратором и возьмите id группы тем же способом либо через
   [@RawDataBot](https://t.me/RawDataBot).)

## Шаг 3. Проверить локально (необязательно, но рекомендуется)

```bash
pip install -r requirements.txt
```

```bash
set BOT_TOKEN=ваш_токен_из_шага_1
set OWNER_CHAT_ID=ваш_id_из_шага_2
python bot.py
```

(Команды `set` — для Windows PowerShell/cmd. Если запускаете из Git Bash —
используйте `export BOT_TOKEN=...` и т.д.)

Напишите своему боту `/start` в Telegram и пройдите весь диалог — заявка
должна прийти вам в личку. Остановить локальный запуск — `Ctrl+C`.

## Шаг 4. Выложить код на GitHub

Render разворачивает бота из GitHub-репозитория.

```bash
git init
git add bot.py requirements.txt README.md .gitignore
git commit -m "Бот для заявок ДЕТИ ЕДЯТ"
```

Создайте пустой репозиторий на [github.com/new](https://github.com/new)
(например `deti-edyat-bot`, можно приватный), затем:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/deti-edyat-bot.git
git branch -M main
git push -u origin main
```

## Шаг 5. Развернуть на Render (бесплатно)

1. Зарегистрируйтесь на [render.com](https://render.com) (можно через GitHub).
2. New → Web Service → выберите репозиторий `deti-edyat-bot`.
3. Настройки:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: Free
4. В разделе Environment добавьте переменные:
   - `BOT_TOKEN` — токен из шага 1
   - `OWNER_CHAT_ID` — id из шага 2
   - `WEBHOOK_URL` — Render покажет URL вида
     `https://deti-edyat-bot-xxxx.onrender.com` ещё до первого деплоя —
     скопируйте его сюда (без завершающего `/`).
5. Нажмите Create Web Service. Первый деплой может завершиться с ошибкой,
   если `WEBHOOK_URL` не был известен заранее — просто откройте вкладку
   Environment, проверьте/впишите правильный URL и нажмите Manual Deploy →
   Deploy latest commit.

**Важно про бесплатный тариф Render:** сервис «засыпает» после ~15 минут без
запросов и просыпается по первому обращению за 20–50 секунд. Для бота это
означает: если клиент первым за долгое время написал `/start`, ответ может
прийти с задержкой до минуты, дальше — уже мгновенно. Если это станет
проблемой при росте заказов — можно перейти на платный инстанс Render
(от $7/мес, без засыпания).

## Шаг 6. Подключить бота на сайте

Сейчас на deti-edyat.ru клиент вручную вписывает Telegram-юзернейм в поле
формы — бот не может первым написать такому клиенту (ограничение Telegram
API). Чтобы автоответы заработали, замените этот способ связи на прямую
ссылку на бота:

- В редакторе Тильды найдите кнопку/блок «Написать в Telegram».
- Замените ссылку на `https://t.me/ВАШ_БОТ_USERNAME` (тот, что задали в
  шаге 1, без `@`).
- Уберите текстовое поле «впишите ваш Telegram» из формы — оно больше не
  нужно, весь диалог теперь проходит внутри бота.

После этого клиент нажимает кнопку → попадает в чат с ботом → жмёт Start →
бот сам собирает заявку и подтверждает её приём.

## Что дальше можно улучшить

- Добавить в диалог даты/период питания, если это нужно для расчёта.
- Хранить заявки не только пересылкой в чат, но и в таблице (Google Sheets/БД).
- Прикрутить бота как альтернативный/дублирующий канал, оставив Тильду для
  заявок по телефону — сейчас они никак не связаны между собой.
